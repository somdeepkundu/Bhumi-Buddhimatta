# Bhumi-Buddhimatta
Open-source, single-file web apps for crop water planning.  
RuDRA Lab · C-TARA · IIT Bombay

## Live apps

| App | Open | What it does |
|---|---|---|
| **JalDHARA** | [Launch](https://somdeepkundu.github.io/Bhumi-Buddhimatta/jaldhara.html) | FAO-56 reference ET (Penman–Monteith, pan, Hargreaves–Samani, Open-Meteo) → crop water need |
| **Crop Kc Finder** | [Launch](https://somdeepkundu.github.io/Bhumi-Buddhimatta/crop_kc_explorer_v2.html) | 36 Maharashtra Kc tables, irrigation calculator, curve fitting |
| **CropView v3** | [Launch](https://somdeepkundu.github.io/cropview-v3/) | Geo-tagged field ground truth (PWA) |
| **Multilingual Crop Kc App** | [Launch](https://somdeepkundu.github.io/crop_kc_app_v3f.html/) | Geo-tagged field ground truth (PWA) |
| **AOI1 ET–NDVI Map** | [Launch](https://somdeepkundu.github.io/Bhumi-Buddhimatta/VNMKV/07_AOI1_ET_NDVI_map.html) | Interactive NDVI–ET visualization for VNMKV AOI1 |
| **Crop Kc Finder v4.1** | [Launch](https://somdeepkundu.github.io/Bhumi-Buddhimatta/VNMKV/Crop%20Kc%20Finder%20v4.1.html) | Updated crop coefficient explorer with local AOI integration |
| **Loni plots, gut by gut** | [Launch](https://somdeepkundu.github.io/Bhumi-Buddhimatta/loni_viewer_v3/loni_plots_per_gut.html) | Map + chart of all 469 Loni Devkar guts on the kharif 2023 drone image: old segmentation model vs new model |
| **Loni plot labeller** | [Launch](https://somdeepkundu.github.io/Bhumi-Buddhimatta/plot_labeller/) | Check the model's plots gut by gut: keep, reject, or draw missed fields; labels train the next model |
| **Loni old map and new map** | [Launch](https://somdeepkundu.github.io/Bhumi-Buddhimatta/loni_viewer_v3/loni_old_vs_new_map.html) | Slide between the old and the new map on the drone image: gut boundaries, roads, streams, ponds and wells |
| **Loni crop ledger** | [Launch](https://somdeepkundu.github.io/Bhumi-Buddhimatta/loni_viewer_v3/loni_crop_ledger.html) | Village map of every Loni Devkar plot, a crop calendar ring per gut, harvest value, crop water use and pump electricity per water year, with sources linked |
| **Pani Hishob** (पाणी हिशोब) | [Launch](https://somdeepkundu.github.io/Bhumi-Buddhimatta/pani_hishob.html) | Crop water productivity (kg and ₹ per m³) for the 49 surveyed Gats of Datli and Musalgaon, 2025-26: satellite ET, Kc × ETo and irrigation, with NDVI and a field calculator |

## Use offline
Download any `.html` file and open it — everything runs locally.  
Map tiles and the optional Open-Meteo fetch need internet; the physics does not.
